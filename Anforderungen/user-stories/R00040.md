# User Story R00040: Dateiliste nach Gruppen

**Als** prüfender Mensch
**möchte ich** die Dateien nach Code, Tests und Doku gruppiert sehen, mit dem Fortschritt je Gruppe,
**damit** ich auf einen Blick weiß, ob ich die Tests zum geänderten Code schon gelesen habe, und Gruppe für Gruppe prüfe.

Vorbereitung: **Repo G** (neu, Wegwerf-Ordner): `g1` „Anlegen“ legt `src/app.js`, `src/Contest.cs`, `src/a.txt`, `tests/app.test.js`, `web/haken-werte.spec.js`, `tests/README.md`, `docs/api.md`, `README.md` mit je einer Zeile an; `g2` „Ändern“ ändert `src/app.js` und `docs/api.md`. **Repo N plus `v`** aus `user-stories/R00014.md`. Programm mit `--kein-browser`, Start in „Zusammen“.

## Szenario 1: Drei Gruppen mit Fortschritt
**Gegeben** `gitreviewA $g1 $g2`, `src/app.js` und `tests/app.test.js` abgehakt
**Wenn** die Liste steht
**Dann** stehen „Code 1 von 3“, „Tests 1 von 3“, „Doku 0 von 2“ in dieser Reihenfolge, und der Kopf nennt „2 von 8 Dateien abgehakt“.

## Szenario 2: Einzeln zeigt nur betroffene Gruppen
**Gegeben** „Einzeln“ mit `g2`
**Wenn** die Liste steht
**Dann** gibt es Code (`src/app.js`) und Doku (`docs/api.md`) mit je „0 von 1“, keine Gruppe Tests.

## Szenario 3: Ausblenden lässt die Zähler stehen
**Gegeben** das Muster `docs/**` und „Abgehakte ausblenden“ an
**Wenn** man `README.md` abhakt
**Dann** verschwinden `docs/api.md` und `README.md` aus der Liste, die Gruppe Doku hat keinen Kopf mehr, und der Kopf zählt beide weiter in m.

## Szenario 4: Die Regel
**Gegeben** die Dateien `tests/README.md`, `src/Contest.cs`, `src/a.txt`
**Wenn** sie eingeordnet werden
**Dann** ist `tests/README.md` Tests, `src/Contest.cs` und `src/a.txt` sind Code.

## Szenario 5: Navigation Gruppe für Gruppe
**Gegeben** nichts abgehakt, `src/app.js` gewählt (letzte Code-Datei)
**Wenn** man `j` drückt und danach `u`
**Dann** ist erst `tests/README.md` gewählt, dann `tests/app.test.js`.

## Szenario 6: Ergebnis unverändert
**Gegeben** zwei Haken und eine Anmerkung
**Wenn** man beendet
**Dann** ist stdout so wie ohne Gruppen.
